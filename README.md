# 네이버페이 구매내역 엑셀 추출 (npay-export)

네이버페이 주문내역을 기간별로 조회해 **일자 · 금액 · 상품명**을 엑셀(.xlsx) 파일로 저장하는 크롬 확장 프로그램입니다.

카드 명세서와 대조하거나, 경비 정산·가계부 정리를 할 때 주문내역을 하나씩 옮겨 적지 않아도 됩니다.

> ⚠️ 네이버와 관련 없는 비공식 도구입니다. 네이버페이 화면 구성이 바뀌면 동작하지 않을 수 있습니다.

## 주요 기능

- 시작일 ~ 종료일 지정 조회 (이번 달 / 지난 달 / 최근 30일 빠른 선택)
- 여러 페이지에 걸친 주문내역을 자동으로 넘기며 수집
- `총 N건 펼쳐보기` 묶음 주문을 펼쳐 상품별로 행을 나눔
- 추가상품은 바로 앞 주문의 결제일로 기록
- 결과를 `구매내역_시작일_종료일.xlsx`로 저장 (금액은 천 단위 구분 숫자 서식)
- 완료 후 건수와 합계 금액 표시

### 출력 예시

| 일자 | 금액 | 상품명 |
|---|---:|---|
| 2026-10-03 | 12,900 | 무선 마우스 |
| 2026-10-05 | 4,500 | 케이블 정리 클립 (추가상품) |
| 2026-10-11 | 31,000 | 생수 2L × 12 (묶음주문 합계) |

## 설치

크롬 웹 스토어에 등록되어 있지 않으므로 개발자 모드로 직접 불러옵니다.

1. 이 저장소를 내려받습니다. (`Code` → `Download ZIP` 후 압축 해제, 또는 `git clone`)
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.

Edge 등 크로미움 기반 브라우저에서도 같은 방식으로 설치할 수 있습니다.

## 사용 방법

1. 네이버에 로그인한 뒤 [네이버페이 주문내역](https://order.pay.naver.com/) 페이지를 엽니다.
2. 툴바의 확장 아이콘을 눌러 기간을 선택합니다.
3. **조회 후 엑셀 저장**을 누릅니다.
4. 페이지가 자동으로 넘어가는 동안 창을 닫지 말고 기다리면 엑셀 파일이 다운로드됩니다.

조회 결과가 0건이거나 내역이 이상하게 나오면 **진단: 화면 텍스트 복사** 버튼으로 현재 화면 텍스트를 클립보드에 복사할 수 있습니다. 이슈를 올릴 때 참고 자료로 활용해주세요. (개인정보가 포함될 수 있으니 공유 전 꼭 확인하세요.)

## 동작 방식

- 네이버페이 API를 호출하지 않고, **현재 열린 페이지에 보이는 텍스트**만 읽습니다. 클래스명은 자주 바뀌기 때문에 화면 텍스트 패턴(`N원`, `MM. DD. 결제`, `자세히 보기` 등)으로 주문 카드를 구분합니다.
- 클릭하는 버튼은 `총 N건 펼쳐보기`와 페이지 번호/다음 페이지 버튼뿐입니다. 삭제·더보기 등 다른 버튼은 누르지 않습니다.
- 연도가 표시되지 않은 날짜는 최신순 정렬을 이용해 연도를 추정합니다.
- 시작일보다 오래된 주문에 도달하면 수집을 멈춥니다. (최대 200페이지)

## 개인정보

- 모든 처리는 브라우저 안에서만 이루어지며, 수집한 내역을 외부 서버로 전송하지 않습니다.
- 요청 권한은 `activeTab`, `scripting`과 `order.pay.naver.com`, `pay.naver.com` 접근뿐입니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `manifest.json` | 확장 프로그램 설정 (Manifest V3) |
| `popup.html` / `popup.js` | 기간 선택 팝업, 엑셀 생성 |
| `scrape.js` | 페이지에 주입되어 묶음 펼치기 · 페이지 이동 · 수집 수행 |
| `parser.js` | 화면 텍스트에서 일자/금액/상품명을 뽑아내는 파서 |
| `xlsx.full.min.js` | [SheetJS](https://sheetjs.com/) 라이브러리 |

## 알려진 제한

- 네이버페이 화면 문구나 구조가 바뀌면 파싱이 실패할 수 있습니다.
- 금액은 화면에 표시된 결제 금액 기준이며, 이후 부분 취소·환불은 반영되지 않을 수 있습니다.
- 묶음 주문을 펼치지 못한 경우 `(묶음주문 합계)`로 한 줄에 기록됩니다.
